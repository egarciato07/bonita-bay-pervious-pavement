
# Research Data Management

## Pervious Pavement Research

### Bonita Bay, Florida

This repository was created for the Research Methods course at Florida Gulf Coast University. My research focuses on evaluating the effectiveness of pervious pavement for flood mitigation and groundwater recharge in Bonita Bay, Florida, particularly under increasingly extreme rainfall events.

The purpose of this repository is to practice research data management using GitHub and the FAIR guiding principles. It provides an introduction to organizing research documentation and making information accessible for future reference and potential reuse.
